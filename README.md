# Ireland Cybersecurity Job Hunt OS 🇮🇪

A personal job-search command centre designed to make my cybersecurity and IT job search in Ireland more organised, measurable, and effective.

## Goal

**Find → Evaluate → Apply → Track → Follow up → Prepare → Improve**

## Version 1

The first version is a static GitHub Pages application using HTML, CSS, vanilla JavaScript, LocalStorage, and JSON where useful.

No backend or exposed API keys are required.
